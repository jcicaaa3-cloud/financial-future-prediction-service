# Project summary

## Title

Financial future prediction service

## Goal

Build a company-quarter pipeline that estimates next-quarter growth, risk, and financial health signals from tabular financial data.

## Input

- Company master data
- Quarterly financial statements
- Market indicators
- Macro indicators
- Disclosure-derived features

## Processing

- Schema validation
- Panel construction
- Feature engineering
- Future label generation
- Baseline model training
- Company-level prediction
- Report generation

## Output

- Prediction JSON
- Decision packet JSON
- Stress test JSON
- Markdown report
- LLM report prompt packet

## Portfolio value

The repository shows the full AI service flow from data contract to model output and report packaging. It is suitable for discussing ML engineering, backend integration, and data pipeline design in interviews.
