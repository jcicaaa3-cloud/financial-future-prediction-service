이 사이트의 역할

GitHub Pages는 서버를 띄울 수 없는 정적 호스팅입니다. 그래서 이 페이지는 누구나 바로 만져볼 수 있는 in-browser scoring simulator로 만들었습니다. 실제 Python/FastAPI 파이프라인은 저장소에서 실행합니다.

안전한 포지셔닝

이 데모는 synthetic example과 설명 가능한 휴리스틱을 사용합니다. 투자 조언, 대출 판단, 신용평가, 실제 기업 등급 산정 용도가 아닙니다.
