# 포트폴리오 설명 문구

## 30초 설명

기업-분기 데이터를 기반으로 다음 분기의 성장 가능성, 위험 신호, 재무 건전성 점수를 예측하는 재무 AI 파이프라인입니다. CSV 입력 계약, 스키마 검증, feature engineering, future label 생성, baseline 모델 학습, JSON 리포트, LLM 보고서 입력까지 연결했습니다.

## 1분 설명

이 프로젝트는 기업의 다음 분기 상태를 조기 진단하는 재무 AI 파이프라인입니다. 재무제표, 시장 지표, 거시경제 지표, 공시 기반 위험 신호를 기업-분기 단위로 병합하고, 다음 분기 기준 라벨을 만들어 성장 가능성, 위험 신호, 재무 건전성 점수를 산출합니다. 결과는 prediction JSON, decision packet, stress test, Markdown report, LLM-ready prompt로 저장됩니다. 현재 sample data는 인공 자료이며, 실제 DART, KRX, 거시경제, 공시 데이터가 들어올 수 있도록 입력 템플릿과 검증 흐름을 분리했습니다.

## RandomForest 질문 대응

RandomForest는 baseline 모델입니다. 이 프로젝트의 평가 대상은 특정 모델 이름보다 데이터 입력 형식, feature 생성, 라벨 생성, 결과 저장 형식, 서비스 연동 흐름입니다. 같은 입력과 출력 구조를 유지하면 LightGBM, XGBoost, CatBoost, temporal model로 바꿀 수 있습니다.

## sample data 질문 대응

sample data는 실제 투자 성과를 주장하기 위한 자료가 아닙니다. 입력 형식, 검증 흐름, 모델 실행, 결과 출력이 끝까지 동작하는지 확인하기 위한 인공 데이터입니다. 실제 데이터 연동 단계에서는 DART, KRX, 거시경제 지표, 공시 텍스트를 연결하고 시간 기준 검증을 수행해야 합니다.

## LLM 질문 대응

LLM은 숫자 예측기를 대체하지 않습니다. 예측 모델이 만든 점수와 근거 필드를 받아 보고서 초안과 의사결정 메모를 작성하는 레이어로 둡니다. 그래서 모델 예측, 설명 필드, 면책 문구를 JSON으로 먼저 고정한 뒤 LLM에 전달합니다.
