# Changelog V3 - Portfolio Edition

## Added

- Static HTML portfolio dashboard generated by the pipeline.
- Batch prediction pipeline and `/v1/batch-predictions` endpoint.
- `/v1/models/latest/leaderboard` endpoint.
- `/v1/models/latest/feature-importance` endpoint.
- Data quality monitoring report.
- Quarter drift smoke-check report.
- Feature snapshot and model-used explanation signals in decision packets.
- `scripts/build_portfolio_snapshot.py` for recruiter-friendly output generation.
- `scripts/check_data_drift.py` for lightweight monitoring outputs.
- Korean portfolio playbook and case-study style documentation.
- Tests for dashboard, batch pipeline, feature importance, and monitoring endpoints.

## Changed

- Version bumped from `0.2.0` to `0.3.0`.
- README repositioned for portfolio review rather than research-paper evaluation.
- Reports and LLM prompts now include feature snapshots and explanation signals.

## Still intentionally limited

- Sample data remains synthetic.
- Feature importance is lightweight sklearn importance, not SHAP or causal explanation.
- The project demonstrates ML/service engineering; it does not claim real financial forecasting validity.
