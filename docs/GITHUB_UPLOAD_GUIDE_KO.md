## 업로드 방법

1. GitHub에서 새 repository를 만든다.
2. README, license, gitignore 자동 생성 옵션은 선택하지 않는다.
3. 압축을 푼 뒤 financial-future-prediction-service 폴더 안의 내용물을 업로드한다.
4. Commit message는 Add financial prediction service portfolio package로 작성한다.
5. 업로드 후 README가 첫 화면에서 정상 렌더링되는지 확인한다.

## 공개 전 확인 항목

- 실제 금융 개인정보가 없는지 확인
- API key, token, password가 없는지 확인
- 회사 내부자료가 없는지 확인
- data/input/sample 파일이 인공 샘플인지 확인
- outputs 폴더의 결과가 sample data 기준이라는 설명이 있는지 확인

## 면접에서 말할 방향

이 프로젝트는 기업-분기 데이터를 받아 다음 분기 상태를 예측하는 재무 AI 파이프라인입니다. 입력 CSV 계약, 검증, feature 생성, baseline 학습, 예측 JSON, 리포트, LLM 보고서 패킷까지 한 흐름으로 묶었습니다. 현재 데이터는 인공 샘플이며, DART, KRX, 거시경제 지표, 공시 데이터로 확장할 수 있도록 입력 형식을 분리했습니다.
